# 🏮 ChineseChess 中國象棋開發規格與使用指南

本專案是一個基於 Spring Boot 3.1.5 的 Java Web 專案，旨在實現一個完整、高效且具有即時互動性的線上中國象棋對弈系統。

---

## 🛠️ 1. 系統開發規格 (Development Specifications)

### 1.1 技術棧 (Tech Stack)
- **後端框架**: Spring Boot 3.1.5
- **語言版本**: Java 17
- **實時通訊**: WebSocket (用於棋盤同步、走棋通知、狀態更新)
- **資料庫**: MySQL (儲存使用者帳號、房間狀態、對局紀錄)
- **緩存系統**: Redis (用於快速存取對局狀態與 Session 管理)
- **前端技術**: HTML5, CSS3, JavaScript (原生 JS 實作 WebSocket 通訊與 SVG 棋盤渲染)

### 1.2 核心功能實作
- **身分認證系統**: 支援使用者註冊與登入，提供 Web 介面與 REST API (`/api/auth`)。
- **房間管理機制**:
  - 支援動態創建房間與加入房間。
  - 房間狀態管理：`WAITING` (待戰中) $\rightarrow$ `PLAYING` (對戰中)。
  - 自動分配角色：首位進入者為紅方 (Red)，第二位為黑方 (Black)。
- **對弈邏輯實作**:
  - **走法驗證**: 嚴格實作中國象棋所有棋子（車、馬、相、仕、將/帥、炮、卒/兵）的移動規則。
  - **特殊規則**:
    - **飛將 (Flying General)**：將與帥不能在同一條垂直線上且中間無棋子。
    - **自陷 (Self-check)**：禁止移動後導致自身將軍暴露在對手攻擊之下的走法。
  - **勝負判定**: 當對方將軍被吃或處於無法逃脫的將死狀態時，判定為獲勝。
  - **中斷處理**：對戰中擅自離開房間的一方直接判定為**輸方**，另一方獲勝。
- **效能優化**:
  - **廣播機制**：採用房間 Session 映射表 (`roomSessions`)，將廣播範圍限定在該對局房間內，避免全域遍歷。
  - **原子更新**：走棋通知 (`MOVE_MADE`) 直接包含最新棋盤狀態，消除前端重複請求同步的延遲。
  - **自動重置**：對局結束後，伺服器自動將棋盤重置為初始位置，方便立即開始下一局。

### 1.3 UI/UX 設計
- **視覺呈現**：使用 SVG 繪製專業棋盤，並以 CSS 漸層與陰影營造棋子立體感。
- **視角翻轉**：黑方玩家進入遊戲後，棋盤會自動執行 180 度翻轉，提供符合對戰習慣的視角。
- **即時反饋**：
  - 「將軍」警示動畫提醒。
  - 即時回合狀態更新 (紅方/黑方操作階段)。
  - 全螢幕勝負宣告覆蓋層 (Game Over Overlay)。

```bash

mvn spring-boot:run
```
- **伺服器地址**: `http://localhost:8088`

### 3.3 頁面導覽
- **首頁**: `/` (index.html) - 登入與註冊。

- **管理後台**: `/admin` (admin.html) - 系統管理 (帳號: admin / 密碼: admin)。
